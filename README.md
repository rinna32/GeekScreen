# GeekScreen

Локальная утилита для скриншотов на Windows x64. Скачайте `GeekScreen-windows-x64.zip` из раздела **Assets** релиза.

1. Распакуйте ZIP и дважды щёлкните по `start.bat`.
2. При первом запуске выберите папку в стандартном окне Windows.
3. Сверните консоль. Во время игры нажимайте **F12**. GeekScreen сохраняет снимок монитора с активным окном в PNG.
4. Чтобы остановить утилиту, закройте консоль или нажмите в ней **Ctrl+C**.

Настройки каждого пользователя хранятся в `%LOCALAPPDATA%\GeekScreen\config.json`. Если папка недоступна при запуске или сохранить снимок не удалось из-за папки, GeekScreen предложит выбрать другую. После смены папки во время игры нажмите F12 ещё раз.

## Полноэкранные игры

С `capture.exe` GeekScreen сначала пробует DXGI Desktop Duplication. При ошибке DXGI или отсутствии файла используется обычный захват экрана. Если игра даёт чёрный кадр, попробуйте режим **«Оконный без рамки»**. Работа захвата зависит от игры, драйвера и режима экрана.

## Сборка для релиза

1. Загрузите исходники в репозиторий, включая папку `.github`.
2. В **Actions** откройте **Build GeekScreen for Windows** и нажмите **Run workflow**.
3. Когда сборка завершится, скачайте артефакт **Windows ZIP**. Внутри него находится готовый `GeekScreen-windows-x64.zip`.
4. Прикрепите этот внутренний ZIP к разделу **Assets** релиза. В нём уже есть `capture.exe`. Пользователям достаточно скачать и распаковать его.
