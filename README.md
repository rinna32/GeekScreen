## Как начать

1. **Скачайте GeekScreen.** В разделе **Releases** справа на странице проекта откройте последний релиз и скачайте **`GeekScreen-windows-x64.zip`**. Кнопка **«Скачать GeekScreen»** выше тоже ведёт к последнему релизу.
2. **Распакуйте архив.** В папке «Загрузки» щёлкните по ZIP правой кнопкой мыши, выберите **«Извлечь всё…»**, затем нажмите **«Извлечь»**.
3. **Запустите GeekScreen.** Откройте распакованную папку и дважды щёлкните по **`start.bat`**. Откроется меню:
   - при первом запуске выберите **`1`** — «Выбрать папку для сохранения»;
   - в окне выбора укажите папку и подтвердите кнопкой **«Да»**, если это правильная папка;
   - после выбора снова появится меню — нажмите **`1`**, чтобы запустить GeekScreen.
4. **Сверните окно GeekScreen, оставив его открытым.** Вернитесь в игру и нажмите **F12**. Снимок появится в выбранной папке как файл PNG.

При следующих запусках папка уже сохранена: в меню сразу будет пункт **`1` — Запустить GeekScreen**.

## Меню

Когда папка ещё не выбрана:

- **`1`** — выбрать папку для сохранения;
- **`2`** — выход.

Когда папка уже выбрана:

- **`1`** — запустить GeekScreen;
- **`2`** — изменить папку;
- **`3`** — выход.

После выбора папки GeekScreen спросит: **«Сохранять скриншоты в эту папку?»**. Нажмите **«Да»**, если всё верно, или **«Нет»**, чтобы выбрать другую.

## Во время игры

- **Что попадает в кадр?** Весь монитор, на котором находится активное окно игры.
- **Куда сохраняются снимки?** В папку, которую вы выбрали при первом запуске. Если она станет недоступна, GeekScreen предложит выбрать другую.
- **Как изменить папку?** Откройте **`start.bat`** и выберите в меню **`2` — Изменить папку**. Новый путь запомнится. Если GeekScreen уже запущен, можно нажать **Ctrl+F12** прямо во время игры.
- **Что делать, если снимок чёрный?** В настройках игры выберите режим **«Оконный без рамки»** и снова нажмите F12.
- **Как остановить GeekScreen?** Закройте его окно. Перед следующей игрой снова откройте **`start.bat`**.
