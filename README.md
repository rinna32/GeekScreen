## Как начать

1. **Скачайте GeekScreen.** В разделе **Releases** справа на странице проекта откройте последний релиз и скачайте **`GeekScreen-windows-x64.zip`**. Кнопка **«Скачать GeekScreen»** выше ведёт туда же.
2. **Распакуйте архив.** Щёлкните по ZIP правой кнопкой мыши, выберите **«Извлечь всё…»** и нажмите **«Извлечь»**.
3. **Запустите GeekScreen.** Откройте распакованную папку и дважды щёлкните по **`start.bat`**.
   - При первом запуске выберите **`1`** — «Выбрать папку для сохранения».
   - Укажите папку и нажмите **«Да»**, если выбрали правильную.
   - В появившемся меню нажмите **`1`**, чтобы запустить GeekScreen.
4. **Сверните окно и вернитесь в игру.** Нажмите **`F11`**. Готовый снимок появится в выбранной папке.

При следующих запусках папка уже сохранена — в меню сразу будет пункт **`1` — Запустить GeekScreen**.

## Меню

Если папка ещё не выбрана:

- **`1`** — выбрать папку для сохранения;
- **`2`** — выход.

Если папка уже выбрана:

- **`1`** — запустить GeekScreen;
- **`2`** — изменить папку;
- **`3`** — выход.

После выбора папки GeekScreen спросит: **«Сохранять скриншоты в эту папку?»**. Нажмите **«Да»**, если всё верно, или **«Нет»**, чтобы выбрать другую.

## Во время игры

- **Что попадает в снимок?** Весь монитор, на котором открыта игра.
- **Куда сохраняются файлы?** В папку, выбранную при первом запуске. Если она станет недоступна, GeekScreen попросит выбрать другую.
- **Как изменить папку?** Закройте окно GeekScreen, снова откройте **`start.bat`** и выберите **`2` — Изменить папку**.
- **Снимок получился чёрным?** В настройках игры выберите режим **«Оконный без рамки»** и нажмите **`F11`** снова.
- **Как остановить GeekScreen?** Закройте его окно. Перед следующей игрой снова запустите **`start.bat`**.
- **Пишет, что GeekScreen уже запущен?** Закройте предыдущее окно GeekScreen и запустите **`start.bat`** ещё раз.
