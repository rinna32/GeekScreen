# GeekScreen

Локальная утилита для скриншотов на Windows с Windows PowerShell 5.1.

1. Распакуйте ZIP и дважды щёлкните по `start.bat`.
2. При первом запуске выберите папку в стандартном окне Windows.
3. Сверните консоль. Во время игры нажимайте **F12**. GeekScreen сохраняет снимок основного монитора в PNG.
4. Чтобы остановить утилиту, закройте консоль или нажмите в ней **Ctrl+C**.

Настройки каждого пользователя хранятся в `%LOCALAPPDATA%\GeekScreen\config.json`. Если папка недоступна при запуске или сохранить снимок не удалось из-за папки, GeekScreen предложит выбрать другую. После смены папки во время игры нажмите F12 ещё раз.

В некоторых играх эксклюзивный полноэкранный режим может давать чёрный кадр. Попробуйте оконный режим без рамки.

Для релиза GitHub упакуйте эти три файла в `GeekScreen-<версия>-windows.zip` и прикрепите архив к релизу в разделе **Assets**.
